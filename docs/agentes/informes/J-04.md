## Verificación

- Mapa: **160×120**, origen **(−80,−60)**; huella `4d86b0d9788c143607d664d15d93243d6634bf2192da86ad5992e397305418f6`. Dos ejecuciones del generador .NET produjeron la misma huella.
- Colisión: **15.343 libres y alcanzables**, **3.857 bloqueadas**. BFS alcanza puertas, claros, rampa y arena; pruebas xUnit verifican también radio de spawners y bases sólidas.
- `NetworkServer.ResolveSpawn` comprueba `MapHashMatches` y devuelve `_config.Spawn` si la huella difiere. Prueba: `Al_Cargar_Personaje_Con_Huella_Distinta_Aparece_En_El_Spawn`.
- `dotnet build Avelora.slnx -v q --nologo`: compilación correcta, **0 errores**, **2 advertencias CS8625** en el layout enlazado (`MapaCiudadLayout.cs`, líneas 292 y 388; asignaciones `null`). No se modificó el cliente para suprimirlas.
- `dotnet test Avelora.slnx`: **1047/1047 correctas**, 0 fallidas, 0 omitidas (base indicada: 1040; se añadieron 7 pruebas).
- Zonas: `server/Avelora.Server/zones.json` y `tools/carga/zones-carga.json` comparados byte a byte; seis JSON de servidor/carga parsean correctamente. `tests`, `tools` y `server` ya no referencian `avelora-valle`.
