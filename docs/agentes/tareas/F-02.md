## 1. Mostrar `LoggedInElsewhere`

En `client/Assets/Avelora/Scripts/Game/NetworkClient.cs`, `DescribeReject` añade:

```csharp
case RejectReason.LoggedInElsewhere:
    return "tu cuenta se ha conectado desde otro sitio";
```

lógica de reconexión: es manual (tecla R) y así debe seguir, para que dos clientes con la misma
cuenta no se echen el uno al otro en bucle.
