## 1. Datos: `deathPenaltyPercent` en `levels.json`

- `LevelTable` (`server/Avelora.Server/Progression/LevelTable.cs`) gana `int DeathPenaltyPercent { get; set; } = 10;`
  (si falta en el JSON vale 10; `LevelTable.Default` también 10).
- `Validate()`: debe estar entre 0 y 100, si no `InvalidOperationException("levels.json: deathPenaltyPercent debe estar entre 0 y 100.")`.
  0 desactiva la penalización.
- Añade `"deathPenaltyPercent": 10` a `server/Avelora.Server/levels.json` y a `tools/carga/levels-carga.json`.
- Método nuevo en `LevelTable`: `int GetDeathPenalty(PlayerEntity player)` →
  `0` si `DeathPenaltyPercent == 0` o `player.Level == MaxLevel`; si no
  `Math.Min(player.Experience, GetExperienceToNext(player.Level) * DeathPenaltyPercent / 100)` (división entera =
  floor; usa `long` para el producto). Nunca negativo. Nunca toca `Level`.

## 2. Servidor: causa de la muerte

Hoy el golpe mortal de un PNJ está en `NpcSystem.cs` (~línea 531, `if (target.Health == 0)`), y
`PlayerVitalsSystem.MarkDeath` cuenta la muerte (`DeathCounted`) en el mismo tick.

- `PlayerEntity` (`Entities/PlayerEntity.cs`) gana `internal bool KilledByNpc { get; set; }`. Se pone a `true`
  en `NpcSystem` dentro de ese `if (target.Health == 0)`, solo si el jugador **no estaba ya muerto**
  (`target.Action != EntityAction.Dead` antes de asignar; evita doble marca). Hoy no hay PvP: **no añadas** rama de
  jugador; deja un comentario de una línea en `MarkDeath` («muerte por jugador o sin causa: no penaliza»).
  Cualquier otra muerte deja `KilledByNpc` en `false`.
- `PlayerVitalsSystem` recibe la `LevelTable` en el constructor (`PlayerVitalsSystem(PlayerVitalsSettings settings, LevelTable levels)`;
  `Zone.cs` ~línea 154 pasa `_levels`, que ya existe en ese punto). Actualiza las llamadas de las pruebas.
- En `MarkDeath`, dentro del bloque que se ejecuta **una sola vez** (tras `player.DeathCounted = true`):
  si `player.KilledByNpc`, `int loss = _levels.GetDeathPenalty(player)`; si `loss > 0`: `player.Experience -= loss`,
  `player.ProgressChanged = true`, `PenalizedDeaths++`, `ExperienceLost += loss`. Después, siempre,
  `player.KilledByNpc = false`.
- `Respawn` también pone `KilledByNpc = false` (por seguridad).
- `Zone` ya dispara `ProgressChanged` (~línea 585) → `NetworkServer.OnProgressChanged` envía `Progress`. No toques
  la red: comprueba que la penalización llega ese mismo tick (la prueba del §4 lo demuestra). Si el orden de
  `Tick` hace que `ProgressChanged` se mire antes de `_vitals.Tick`, indica en el informe cómo lo resolviste
  (el aviso puede llegar al tick siguiente; no mueve el sistema de sitio si no hace falta).
- Persistencia: `Experience` ya se guarda al desconectar y en el guardado periódico; no cambies `Persistence/`.
  La prueba de reconexión (§4) debe confirmarlo.

## 4. Pruebas (xUnit)

En `tests/Avelora.Tests/` (archivo nuevo `I11Tests.cs`; copia el montaje de `I03Tests.cs` para muerte por PNJ):

- **Datos:** `deathPenaltyPercent` por defecto 10 si falta; −1 y 101 se rechazan con el mensaje; 0 y 100 válidos.
- **`GetDeathPenalty`:** nivel 1, umbral 100, XP 50 → 10; XP 5 → 5 (recortada); nivel 3 umbral 225 → floor(22,5) = 22;
  porcentaje 0 → 0; nivel máximo → 0.
- **Muerte por PNJ:** jugador nivel 1 con 50 XP muere por un PNJ → XP 40, `Level` sigue 1, `PenalizedDeaths` 1,
  `ExperienceLost` 10.
- **Mínimo 0:** XP 3 con pérdida 10 → XP 0, nivel intacto.
- **Nivel máximo:** no pierde, `PenalizedDeaths` 0.
- **Porcentaje 0:** no resta.
- **Sin causa:** una muerte con `KilledByNpc = false` (por ejemplo forzando `Health = 0` sin pasar por `NpcSystem`) no resta.
- **Una sola vez:** muchos ticks muerto no vuelven a restar.
- **Progress:** tras la muerte penalizada el servidor envía `Progress` con la XP nueva (usa el montaje de
  `NetworkServerTests.cs` que ya comprueba `Progress`).
- **Persistencia:** penalizado, desconectar y reconectar (`PersistenceTests.cs`, mismo estilo): la XP penalizada se conserva.
