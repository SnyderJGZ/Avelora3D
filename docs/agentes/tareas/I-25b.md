## 2. Recibir `LootGained` (`NetworkClient.cs`)

En el `switch` (junto a `case MessageType.CombatEvent:`, ~1175):

```csharp
case MessageType.LootGained:
    if (_welcomeReceived &&
        MessageCodec.TryReadLootGained(buffer, offset, length, out LootGainedMessage loot))
    {
        HandleLootGained(loot);
    }

    break;
```

`HandleLootGained` añade líneas en este orden (una por cada una que toque; `line` empieza en 0 y sube):

1. `Experience > 0` → `"+" + Experience + " exp"`, color `new Color(0.6f, 0.85f, 1f)`.
2. `Gold > 0` → `"+" + Gold + " oro"`, color `new Color(1f, 0.85f, 0.25f)`.
3. Cada objeto con `OnGround == false` → `Nombre(id)` y, si `Count > 1`, `" x" + Count`; color blanco.
4. Cada objeto con `OnGround == true` → `"Inventario lleno: " + Nombre(id) + (Count > 1 ? " x" + Count : "") + " al suelo"`,
   color `new Color(1f, 0.45f, 0.35f)`.

Todas con el mismo `StartTime = Time.unscaledTime`. Tope: si al añadir `_lootTexts.Count == 16`, quita la más
vieja (`RemoveAt(0)`) como hace `AddDamageNumber` (~1268). Un mensaje con 32 objetos solo deja ver los últimos:
es aceptable (no pasa con los datos actuales).
