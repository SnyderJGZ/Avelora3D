## Decisiones tomadas (no las cambies)

1. **La velocidad la decide el servidor:** al recibir `StatusEffects` el cliente llama a
   `_prediction.SetSpeed(pct == 100 ? _welcomeSpeed : _welcomeSpeed * pct / 100f)` (misma expresión que el servidor).
   Nunca cambia la velocidad por su cuenta (ni al acabar la cuenta atrás local).
2. **Estados de los demás:** solo la máscara de `StatusEvent`, como rótulo de letras sobre la entidad, sin duración.
   Al desaparecer una vista remota se olvida su máscara.
3. **Estados propios:** la lista de `StatusEffects` con cuenta atrás local desde que llegó el mensaje; cada mensaje
   nuevo la sustituye entera.
4. **Habilidades amistosas** (`Effect == 1` o `StatusKind` `Bonus`/`Shield`) se lanzan como la cura de I-17b: sobre uno
   mismo salvo con un jugador seleccionado.
5. **Absorbido:** número celeste entre paréntesis, sin proyectil.

## 3. Rótulos sobre las entidades (`NetworkClient.Gui.cs`)

- `private static readonly string[] StatusMaskTexts` de 16 cadenas creadas una vez: para cada máscara, las letras de
  sus bits separadas por espacio en este orden: bit 0 `B` (bonus), bit 1 `E` (escudo), bit 2 `L` (lento), bit 3 `P`
  (provocado). Índice 0 = `""`. Así no se crean cadenas por fotograma.
- `private void DrawStatusMarks()`, copiando `DrawPvpMarks` (~214) y llamado justo después de él en `OnGUI` (~104):
  por cada vista remota viva con máscara en `_statusMasks`, rótulo `StatusMaskTexts[mask]` en
  `view.transform.position + Vector3.up * 1.2f` (el «PvP» está a 0.9), 64×18, color `new Color(0.6f, 0.9f, 1f)`. Y
  lo mismo para el propio jugador con `transform.position` si `_statusMasks` tiene `_entityId`.

## 4. Panel propio con cuenta atrás (`NetworkClient.Gui.cs`)

`private void DrawOwnStatuses()`, llamado justo después de `DrawOwnHealth()` en `OnGUI` (~100). Por cada uno de los
`_ownStatusCount`: `float left = Mathf.Max(0f, entry.RemainingTicks / (float)SimulationConstants.TickRate -
(Time.unscaledTime - _ownStatusReceivedAt));` si `left <= 0` no se dibuja (el servidor mandará la lista nueva). Cajas
de 120×20 en fila, centradas sobre el marco de la vida (`y = Screen.height - 146f`), fondo oscuro y texto:
- `Bonus` → `"Bonus +" + Amount + " · " + left.ToString("0") + " s"` (amarillo);
- `Shield` → `"Escudo " + Amount + " · …"` (celeste; `Amount` es lo que queda);
- `Slow` → `"Lento " + Amount + " % · …"` (azul);
- `Taunt` → `"Provocado · …"` (rojo; no debería llegar a un jugador).

## 5. Panel K y lanzamiento

- `SkillKindText` (`.Gui.cs` ~1014): `kind` = `Effect == 1` → «cura»; `Effect == 2` → `""`; `Radius > 0f` → área
  como hoy; si no, «un objetivo». `status` = nuevo `private static string StatusText(SkillCatalogEntry skill)`, con
  `s = (skill.StatusTicks / (float)SimulationConstants.TickRate).ToString("0.#")`: `Bonus` → `"bonus +" + Amount + "
  · " + s + " s"`; `Shield` → `"escudo " + Amount + "+ · " + s + " s"` (el «+»: crece con el atributo); `Slow` →
  `"ralentiza " + Amount + " % · " + s + " s"`; `Taunt` → `"provoca · " + s + " s"`; `None` → `""`. Devuelve `kind`
  y `status` unidos por `" + "`, o el que no esté vacío. Si no cabe en la fila, dilo en el informe en vez de mover
  columnas.
- `TryUseSkill` (`NetworkClient.cs` ~923): la condición `skill.Effect == 1` del lanzamiento sobre uno mismo pasa a
  `IsFriendly(skill)` (nuevo `private static bool IsFriendly(SkillCatalogEntry s) => s.Effect == 1 || s.StatusKind ==
  StatusKind.Bonus || s.StatusKind == StatusKind.Shield;`). Tras comprobar `target == null`: si `skill.StatusKind ==
  StatusKind.Taunt && target.Kind != EntityKind.Npc` → `ShowHint("provocar solo vale con enemigos")` y `return`.
