## 3. Recarga del ataque con prisa (`NetworkClient.cs` ~714-736)

`CurrentWeapon(out float attackRange, out float attackCooldown)` devuelve la recarga base del arma. Después de esa
llamada (y antes de usar `attackCooldown`, ~736 `_nextAttackAt = Time.unscaledTime + attackCooldown`) aplica la prisa:

```csharp
// Mismo cálculo que el servidor (CombatMath.AttackCooldownTicks con prisa): techo en ticks, mínimo 8 ticks.
float baseTicks = Mathf.Ceil(attackCooldown * SimulationConstants.TickRate - 0.001f);
float hasteTicks = Mathf.Ceil(baseTicks * 10000f / (10000f + _stats.Haste) - 0.001f);
attackCooldown = Mathf.Max(8f, hasteTicks) / SimulationConstants.TickRate;
```

Si `SimulationConstants.TickRate` no existe en el cliente (comprueba `shared/` tras la copia), usa el campo donde ya se
guarda la tasa de ticks del `Welcome`; si tampoco, escribe `20f` con un comentario `// 20 Hz, igual que el servidor`.
El `8f` es `minAttackTicks` de `classes.json`; déjalo como constante privada `private const float MinAttackTicks = 8f;`
con ese comentario. Esto solo evita mandar ataques que el servidor rechazaría por recarga: el servidor decide.
