## 4. Minimapa (`NetworkClient.Gui.cs`)

Método nuevo `DrawMinimap()`, llamado justo después de `DrawZoneLabel()`. Sale sin dibujar si
`_map == null || _map.Grid == null`.

**Textura** (solo cuando `_minimapDirty` o `_minimapTexture == null`; nunca por fotograma):
- `MapCollisionGrid grid = _map.Grid;` destruye la anterior si existe y crea
  `new Texture2D(grid.Width, grid.Height, TextureFormat.RGBA32, false) { filterMode = FilterMode.Point, wrapMode = TextureWrapMode.Clamp }`.
- Un `Color32[] pixels` de `Width * Height`; píxel `(px, py)` = casilla `(grid.OriginX + px, grid.OriginY + py)`,
  índice `py * Width + px` (la fila 0 de la textura es la de abajo, igual que `y` crece hacia arriba en el mapa):
  - bloqueada (`grid.IsTileBlocked`) → `(20, 20, 24, 255)`; libre → `(70, 82, 70, 255)`.
- Después, zonas: por cada zona de `_zones`, por cada rectángulo, por cada casilla dentro de la textura: `Pvp` →
  `(170, 60, 55, 255)` salvo que el píxel ya sea de zona segura; `Safe` → `(70, 170, 90, 255)` siempre (prioridad
  segura > PvP, como el servidor). Para saber si ya es segura, pinta primero todas las `Pvp` y luego todas las `Safe`.
  Las casillas bloqueadas dentro de una zona conservan el color de pared.
- `SetPixels32(pixels); Apply(false); _minimapDirty = false;`

**Dibujo** (cada `OnGUI`):
- `scale = Mathf.Min(200f / grid.Width, 150f / grid.Height)`; `size = (grid.Width * scale, grid.Height * scale)`;
  `rect = new Rect(Screen.width - size.x - 12f, 12f, size.x, size.y)`.
- `GUI.Box` 4 px más grande alrededor; `GUI.DrawTexture(rect, _minimapTexture)`.
- Jugador: si `TryGetEntityPosition(_entityId, out Vector3 self)` (~1250), punto blanco de 4×4 en
  `x = rect.x + (self.x - grid.OriginX) * scale - 2f`, `y = rect.yMax - (self.y - grid.OriginY) * scale - 2f`
  con `GUI.DrawTexture(..., Texture2D.whiteTexture)` y `GUI.color = Color.white` (restaura después).
- Si choca con otra ventana o panel que hoy se dibuje arriba a la derecha, dilo en el informe y no la muevas.
