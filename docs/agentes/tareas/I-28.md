## 1. Fórmula de equilibrio (§2.8 del plan, entera)

Constantes (todas en `classes.json`, §2.1):

| Campo | Valor | Qué es |
| --- | ---: | --- |
| `critPerDex` | 10 | pb de crítico por punto de DES |
| `critCap` | 4000 | tope de crítico (40 %) |
| `critMultiplier` | 150 | daño de un crítico, % del golpe |
| `hastePerDex` | 15 | pb de prisa por punto de DES |
| `hasteCap` | 3000 | tope de prisa (30 %) |
| `minAttackTicks` | 8 | recarga mínima del ataque básico (0,4 s) |
| `pvpDamagePercent` | 60 | % del daño que un jugador hace a otro jugador |
| `critBase` (por clase) | 800 / 800 / 800 / 300 | guerrero, mago, ranger, sanador |

```
golpe       = ⌊arma × (100 + primario × powerPerPoint) / 100⌋           (I-27, sin cambios)
golpeCrít   = ⌊golpe × critMultiplier / 100⌋
critPb      = mín(critCap, critBase(clase) + DES × critPerDex)           DES = efectivo (base + puntos + equipo)
prisaPb     = mín(hasteCap, DES × hastePerDex)
recargaTick = máx(minAttackTicks, ⌈ticksArma × 10000 / (10000 + prisaPb)⌉)   ticksArma = AttackCooldownTicks(segundos)
E[golpe]    = golpe + critPb / 10000 × (golpeCrít − golpe)
DPS_esp     = E[golpe] × 20 / recargaTick
              ≈ golpe × (1 + probCrit × (multCrit − 1)) × (1 + prisa) / recargaArma            (lectura continua)
mitigado    = máx(1, ⌊bruto × 100 / (100 + defensa)⌋)                    (sin cambios)
PvP         = máx(1, ⌊mitigado × pvpDamagePercent / 100⌋)                solo jugador contra jugador, después de la mitigación
```

- Orden de un golpe de jugador: bruto → crítico (tirada) → mitigación → PvP (si la víctima es jugador) → escudo →
  vida. Las curas pueden ser críticas (`⌊cura × critMultiplier / 100⌋`) y **no** se reducen por PvP; los escudos y los
  PNJ no tiran crítico.
- La tirada es `Random.Next(10000) < critPb`, **solo si `critPb > 0`** (así un catálogo sin crítico no consume azar).
  El `Random` está sembrado con `ServerConfig.CombatSeed` (§5.1) y se puede inyectar en las pruebas.
- La prisa solo afecta al ataque básico. Las recargas de habilidades no cambian.
- El equipo no aporta crítico ni prisa (no hay campos): `DES` efectivo sí cuenta el equipo (los guantes dan DES +1).

## 4. `CombatMath` y `CharacterStats` (`server/Avelora.Server/Progression/`)

Nuevos en `CombatMath` (todos `public static`, `/// <summary>`, **sin** nombres de clases concretas):
- `int CritChancePb(ClassCatalog catalog, int classId, int dex)` → `mín(CritCap, critBase + dex × CritPerDex)`
  con `checked`.
- `int HastePb(ClassCatalog catalog, int dex)` → `mín(HasteCap, dex × HastePerDex)`.
- `long AttackCooldownTicks(double cooldownSeconds, int hastePb, int minTicks)`: `base = AttackCooldownTicks(segundos)`;
  devuelve `Math.Max(minTicks, (base × 10000 + (10000 + hastePb) − 1) / (10000 + hastePb))` (división entera con techo,
  en `long`). `hastePb < 0` → `ArgumentOutOfRangeException`. La sobrecarga de un parámetro no cambia.
- `int CritDamage(int rawDamage, int multiplierPercent)` → `⌊raw × mult / 100⌋` con `long`.
- `int PvpDamage(int mitigated, int pvpPercent)` → `Math.Max(1, ⌊mitigated × pct / 100⌋)`.
- `double ExpectedDamage(int rawDamage, int critChancePb, int multiplierPercent)` →
  `raw + critChancePb / 10000.0 × (CritDamage(raw, mult) − raw)`.
- `double ExpectedHit(int rawDamage, int critChancePb, int multiplierPercent, int defense, int pvpPercent = 100)`:
  `f(x) = Mitigate(x, defense)` y, si `pvpPercent < 100`, `PvpDamage(f(x), pvpPercent)`; devuelve
  `(1 − p) × f(raw) + p × f(CritDamage(raw, mult))` con `p = critChancePb / 10000.0`.

`CharacterStats.cs`: `DerivedCharacterStats` (~160) gana `CritChancePb` y `HastePb` como **últimos parámetros
opcionales** del constructor (`int critChancePb = 0, int hastePb = 0`) y propiedades. `Calculate` los rellena con
`CombatMath.CritChancePb(catalog, classId, dex)` y `CombatMath.HastePb(catalog, dex)` usando la `dex` ya con el equipo
sumado (la misma que devuelve `Dex`).
