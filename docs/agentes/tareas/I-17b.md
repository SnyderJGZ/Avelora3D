## Decisiones tomadas (no las cambies)

1. **Cura sin objetivo, o con un PNJ seleccionado, se lanza sobre uno mismo** (`targetId = _entityId`). Con un jugador
   seleccionado, sobre ese jugador. Así el sanador se cura en pleno combate sin deseleccionar al orco.
2. **La cura se ve como número verde con «+»** (`CombatEvent` con `Heal`), sin proyectil.
3. **El área se dibuja solo al recibir `SkillUsed`** (servidor aceptó), como un anillo de puntos de radio
   `entry.Radius` en la posición actual del objetivo `TargetId`, durante 0.35 s. Si el objetivo ya no se ve, no se
   dibuja.

## 1. Cura en verde (`NetworkClient.cs` y `.Gui.cs`)

- `struct DamageNumber` (`NetworkClient.cs` ~119): campo nuevo `public bool Heal;`.
- `AddDamageNumber` (~1620): `Heal = (flags & CombatEventFlags.Heal) != 0` y el texto, si es cura,
  `"+" + damage` (sin «!»).
- `HandleCombatEvent` (bucle ~1550): una entrada con `Heal` **nunca** crea proyectil (va directa a `AddDamageNumber`),
  aunque traiga `Ranged`.
- `DrawCombatEffects` (`NetworkClient.Gui.cs` ~440): `Color color = number.Heal ? new Color(0.35f, 1f, 0.4f) :
  (number.OnSelf ? … : Color.white);` (la cura gana a «sobre mí»).

## 2. Área dibujada (`NetworkClient.cs` y `.Gui.cs`)

- Junto a `CombatProjectile` (~108): `private struct AreaFlash { public Vector3 Center; public float Radius; public
  float StartTime; }` y, junto a `_projectiles` (~136), `private readonly List<AreaFlash> _areaFlashes = new
  List<AreaFlash>(8);`.
- `case MessageType.SkillUsed` (~1513): tras poner la recarga, si `entry.Radius > 0f &&
  TryGetEntityPosition(skillUsed.TargetId, out Vector3 center)` → si `_areaFlashes.Count == 8` quita el 0; añade
  `new AreaFlash { Center = center, Radius = entry.Radius, StartTime = Time.unscaledTime }`.
- `DrawCombatEffects` (~377): al principio, quita los que tengan `now - StartTime >= 0.35f`. Después de los
  proyectiles (~428), por cada uno: 24 puntos `center + new Vector3(Mathf.Cos(a), Mathf.Sin(a), 0f) * radius`
  (`a = k * 2π / 24`), `cam.WorldToScreenPoint`, salta si `z < 0`, y `GUI.DrawTexture` de 5×5 con
  `GUI.color = new Color(1f, 0.55f, 0.2f, 1f - (now - StartTime) / 0.35f)`. Restaura `GUI.color` como ya hace el método.
  Sin listas ni cadenas nuevas por fotograma.
